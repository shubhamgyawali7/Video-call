

# Video-Call Application

A real-time peer-to-peer video calling application built using **WebRTC**, **Socket.io**, and **Node.js**.

## 🚀 Features

* **Real-time Video/Audio:** High-quality low-latency communication.
* **Peer-to-Peer Connection:** Direct data transfer between users using WebRTC.
* **Signaling Server:** Managed via Socket.io to handle connection handshakes.
* **Room Creation:** Users can create or join specific rooms using unique IDs.
* **Responsive UI:** Works on both Desktop and Mobile browsers.

## 🛠 Tech Stack

* **Frontend:**  Next.js
* **Backend:** Node.js, Express
* **Real-time Engine:** Socket.io
* **Web API:** WebRTC (RTCPeerConnection, MediaDevices)

## 📦 Installation & Setup

1. **Clone the repository:**
```bash
git clone https://github.com/shubhamgyawali7/Video-call.git
cd Video-call

```


2. **Install dependencies:**
```bash
npm install

```


3. **Environment Variables:**
Create a `.env` file in the root directory (if applicable):
```env
PORT=3000

```


4. **Run the application:**
```bash
npm run dev

```


The app should now be running on `http://localhost:3000`.
